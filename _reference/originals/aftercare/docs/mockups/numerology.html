The method

Plain arithmetic, shown.

Reduce the month, day and year separately, add them, reduce again. Keep 11, 22 and 33 as master numbers. Name numbers use the Pythagorean letter table (A=1 ... I=9, J=1 ...).

Numerology is a reflective tradition, not a science. Use it as a conversation starter with yourself.
