# Synthetic examples

**Everything in this folder is SYNTHETIC.** These are invented app ideas and briefs, written to illustrate the Aftercare pattern. They are not real projects or real user requests. Each record has `"synthetic": true`.

- `strong-briefs.jsonl`: 20 records, `{id, synthetic, label, app_name, user_idea, ideal_builder_brief}`. They cover varied app types: garden, finance, kids' game, music, wellness, genealogy, productivity, encyclopedia, puzzle, astronomy, maps, divination, transit, journaling, design tool, reading, arcade, tea and drawing. Eight use three.js with the software-GL test note.
- `weak-briefs.jsonl`: 5 records, `{id, synthetic, label, weak_brief, why_it_fails}`. Each is a contrasting anti-pattern, annotated.
