# User prompt template (for whoever pitches the idea)

You don't need all of this. The starred lines are what made the Aftercare prompt work.

```
<App name> is <one-line vision>.
* It knows/does: <3-8 concrete nouns: profile fields, objects, data>.
* The heart of it: <the one signature interaction, e.g. "3D flip cards", "drag cities on a map">.
Later (not now): <marketplace, community, accounts, ...>.
* Start by building: <the first slice> plus mockups (desktop + mobile).
Vibe: <2-3 adjectives or a reference: "a well-loved almanac", "90s arcade">.
Don't: <anything off-limits: copying a brand, medical claims, ...>.
```

**Example** (synthetic):
> Pantry Pal is a cooking buddy that knows what's in my kitchen. It knows: my pantry items, expiry dates, the recipes I've saved and my allergies. The heart of it: drag ingredients into a pot and it suggests what you can cook. Later: shopping lists, sharing with roommates, a recipe community. Start by building the pantry and the drag-to-pot screen, plus mockups. Vibe: a cozy hand-lettered recipe card. Don't: give nutrition or medical advice.
