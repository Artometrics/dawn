# Dawn Code

Mode: operate

Audience: Kyle, alone, at a desk on the Hetzner box. Job: read and change code with a model, then accept a diff. Action: ask, inline-edit, run an agent pass, or hand a task to a Dawn agent.

Constraints: one user, keys only in env, shared $20 cap, Artometrics blue `#0047ff` and pink `#ff3d8a` on a dark ground. Do not restyle the village. Edits stay unwritten until accept.

## Direction contract

THESIS: Dawn Code is the VS Code workbench with a sidebar that answers about the open file and will not write until Kyle accepts a diff. It refuses a chat-app page and the village night list.

OWN-WORLD: Near-black IDE ground. Blue `#0047ff` is the send button, the selected tab, and the healthy spend filament. Pink `#ff3d8a` is the cursor, the cap warning, and the handoff. UI sans for the panel. Mono only for code. One filament under the title.

STORY: Kyle asks about the selection, requests an inline change or a multi-file pass, reads the diff, and accepts or rejects. The month's estimated spend sits against the shared cap. Sending to a Dawn agent is a separate handoff, and a stub says so when that API is not merged.

FIRST VIEWPORT: The VS Code shell is the product. The Dawn Code view holds the title, the spend line, the filament, Chat / Inline / Agent tabs, the transcript, then the model select, the open-file line, the prompt, and Send.

FORM: Brief-pinned Artometrics dark on a code editor. No concept-seed roll; the palette and the VS Code shell were specified. Signature move is the spend filament, blue while the month is under 80 percent and pink from there to the cap.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
